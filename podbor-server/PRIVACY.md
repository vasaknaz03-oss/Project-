## Какие данные обрабатываются

1. **Анонимный идентификатор устройства.** При первом обращении к серверу программа получает случайный токен.
   Он не связан с вашим именем, e-mail или учётными записями и нужен только для суточных лимитов.
2. **Запросы к функциям сервера:** тексты поисковых запросов (например «RTX 5070 обзор»), идентификаторы товаров
   Onliner для разбора отзывов, параметры поиска объявлений Kufar. Результаты хранятся в общем кэше без привязки
   к устройству и удаляются по истечении срока хранения (сутки — для данных YouTube, до 14 дней — для остального).
3. **IP-адрес** — только в виде хэша и не дольше двух часов, для защиты от массовой регистрации.
4. **Telegram:** если вы подключили уведомления — идентификатор чата с ботом ПодборПК. Удаляется командой `/stop`
   или кнопкой «Отключить» в программе.
5. **Счётчики использования** (сколько запросов сделано за день) — хранятся 40 дней.

Сборки, настройки, история слежения и собственные ключи пользователя хранятся **только на вашем компьютере**
и на сервер не передаются.

## Сторонние сервисы

- **YouTube API Services** — для поиска видео. Используя эту функцию, вы соглашаетесь с
  [Условиями использования YouTube](https://www.youtube.com/t/terms); обработка данных Google — по
  [Политике конфиденциальности Google](https://policies.google.com/privacy).
- **Anthropic (Claude)** — для ИИ-выжимок: на сервер Anthropic передаётся текст запроса (без идентификатора устройства).
- **Telegram** — для доставки уведомлений.
- **Onliner, Kufar** — открытые данные каталога и объявлений.

## Ваши права

Вы можете перестать пользоваться сервером (выключить его в «Настройках» программы), отключить Telegram-уведомления
и запросить удаление данных устройства, написав на [контактный e-mail].

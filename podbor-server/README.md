# Сервер ПодборПК

Небольшой сервер-посредник для массового выпуска программы. Программа обращается не к YouTube, Anthropic
и Telegram напрямую, а к этому серверу, и уже он ходит во внешние сервисы с **вашими** ключами.

| Что делает | Зачем |
|---|---|
| Хранит ключи Anthropic, YouTube и Telegram | В программе ключей нет — их нельзя украсть из установщика |
| **Общий кэш** для всех пользователей | Если 500 человек ищут «RTX 5070 обзор», запрос в YouTube уходит один раз, остальные получают сохранённый ответ. То же для ИИ-выжимок и разбора отзывов |
| Лимиты на устройство в сутки и общий дневной бюджет на ИИ | Счёт за ИИ не улетит; заготовка под платный тариф (`pro`) |
| Собирает данные Onliner и Kufar один раз для всех | Тысячи копий программы не листают Kufar сами — нагрузка на сайты минимальна |
| Общий Telegram-бот | Пользователь нажимает «Подключить Telegram» и «Старт» — без @BotFather |

Устройства регистрируются анонимно: сервер выдаёт программе случайный токен и по нему считает лимиты.
Никаких логинов, e-mail и паролей.

## Что понадобится

1. **Сервер (VPS)** с Linux — подойдёт самый простой: 1 vCPU, 1–2 ГБ памяти, 20 ГБ диска (от нескольких $ в месяц:
   Hetzner, DigitalOcean, Vultr, Timeweb Cloud, Selectel и т. п.).
2. **Домен** (например `api.podborpk.by`) — A-запись в DNS на IP сервера. HTTPS-сертификат получится сам.
3. Ключи (каждый можно добавить позже — без ключа функция просто выключена):
   - **ИИ — один из двух вариантов:**
     - **своя модель (бесплатно):** Ollama в том же Docker — `docker compose --profile ollama up -d`, затем
       `docker compose exec ollama ollama pull qwen3:4b`; в `.env`: `AI_BASE_URL=http://ollama:11434`, `AI_MODEL=qwen3:4b`,
       `AI_KIND=ollama`. Нужен сервер с 8+ ГБ памяти; без видеокарты ответ идёт минуты, поэтому лимиты ИИ держите небольшими.
       Подойдёт и любой OpenAI-совместимый сервис: `AI_BASE_URL`, `AI_MODEL`, `AI_API_KEY`, `AI_KIND=openai`;
     - **Anthropic** — [console.anthropic.com](https://console.anthropic.com/settings/keys) → API Keys (доступен не во всех странах).
       Оплата по факту использования; в `.env` задайте дневной бюджет `AI_DAILY_BUDGET_USD`. Если ключ задан, он главнее своей модели.
   - **YouTube Data API v3** — [Google Cloud Console](https://console.cloud.google.com/apis/library/youtube.googleapis.com) →
     «Включить» → «Учётные данные» → «Создать ключ API». Бесплатно, 10 000 единиц в день.
   - **Telegram-бот** — в Telegram у [@BotFather](https://t.me/BotFather): `/newbot`, имя «ПодборПК», адрес вроде `podborpk_bot`.

## Запуск (≈10 минут)

```bash
# 1. На сервере: установить Docker
curl -fsSL https://get.docker.com | sh

# 2. Скачать код
git clone https://github.com/<владелец>/<репозиторий>.git podbor && cd podbor/podbor-server

# 3. Настройки и ключи
cp .env.example .env
nano .env            # DOMAIN, ADMIN_TOKEN, ключи, лимиты

# 4. Запустить (сервер + Caddy с автоматическим HTTPS)
docker compose up -d --build

# 5. Проверить
curl https://ВАШ_ДОМЕН/v1/health
```

Обновление: `git pull && docker compose up -d --build`. Данные (SQLite, кэш, индексы Kufar) лежат в томе
`podbor-data` и переживают обновления.

## Подключить программу к серверу

Адрес сервера «вшивается» в программу при сборке установщиков:

- в репозитории GitHub: **Settings → Secrets and variables → Actions → Variables → New variable**,
  имя `PODBOR_SERVER`, значение `https://ВАШ_ДОМЕН` — следующая сборка в Actions подставит его сама;
- или вручную: поле `"podborServer"` в `pc-builder/package.json`.

Пользователь может поменять адрес или выключить сервер в «Настройках» программы. Если сервер недоступен,
программа продолжает работать сама (данные Onliner и Kufar — напрямую, ИИ — по своему ключу, если задан).

## Статистика и тарифы

```bash
curl -H "X-Admin-Token: ВАШ_ADMIN_TOKEN" https://ВАШ_ДОМЕН/v1/admin/stats
```

Покажет число устройств, активных за сутки и неделю, использование за сегодня, расходы на ИИ и размер кэша.

Платный тариф (заготовка): `POST /v1/admin/plan` с телом `{"device": "<id устройства>", "plan": "pro"}` —
у устройства станут лимиты `LIMIT_PRO_*`. Приём оплаты (bePaid, Stripe и т. п.) подключается отдельно и
вызывает этот метод.

## Квота YouTube

10 000 единиц в день: поиск стоит 100 единиц, комментарии — 1. Благодаря общему кэшу (сутки) этого хватает на
много пользователей: популярных запросов немного. Когда появится аудитория, подайте заявку на увеличение квоты
(бесплатно): **YouTube API Services — Audit and Quota Extension Form** (ссылка есть в Google Cloud Console на
странице квот YouTube Data API). Google проверит соблюдение правил:

- нужна **политика конфиденциальности** — шаблон в [PRIVACY.md](PRIVACY.md), опубликуйте её на своём сайте;
- видео показываются с названием канала и ссылкой на YouTube — программа так и делает;
- данные API не хранятся дольше ~30 дней без обновления — сервер хранит их сутки (`TTL_YOUTUBE_HOURS`, максимум 29 дней).

## Onliner и Kufar

Сервер забирает только открытые JSON API (каталог Onliner, поиск Kufar) и кэширует ответы на 5–15 минут;
полный просмотр объявлений Kufar для «Сначала выгодные» делается один раз для всех с паузами между страницами.
Для коммерческого продукта стоит проверить правила этих сайтов или договориться с ними.

## Без Docker

Нужен Node.js 22.13+: `cd pc-builder && npm ci --omit=dev && cd ../podbor-server && npm start`
(переменные окружения — как в `.env.example`). За HTTPS-прокси (nginx/Caddy) задайте `TRUST_PROXY=1`.

## Проверка

`npm test` в папке `podbor-server` — проверки на поддельных Telegram, YouTube и ИИ (без настоящих ключей).

# ПодборПК — подбор комплектующих для ПК в Беларуси

Программа для **Windows и macOS**, которая собирает компьютер под ваш бюджет по живым ценам белорусских магазинов.

- **Бюджет в любой валюте:** BYN, USD, EUR, RUB, PLN, CNY и других. Курс берётся с НБРБ, при желании можно задать свой.
- **Назначение:** игры, универсальный ПК, работа (монтаж, 3D, код), офис и учёба.
- **Три варианта сразу:** «Экономнее» (−15 %), «Оптимально», «С запасом» (+15 %) и таблица их сравнения.
- **Совместимость проверяется автоматически:** сокет, тип памяти, мощность блока питания, нужен ли кулер, влезет ли плата и кулер в корпус, есть ли видеовыход без видеокарты.
- **У каждой детали:**
  - цены во всех магазинах Onliner: магазин, город, рейтинг, гарантия;
  - альтернативы дешевле и дороже с разницей в цене и производительности, замена в один клик;
  - б/у объявления той же модели на Kufar со скидкой в процентах;
  - ссылки на поиск в Kufar, 21vek, DNS, 5 элемент, Shop.by и Google.
- **Фильтры как на Onliner — и в подборе, и в поиске.** Для каждой детали доступны те же фильтры, что на сайте Onliner: производитель, чипсет, графический процессор, объём и частота памяти, подсветка, цвет корпуса, модульность и сертификат БП, СЖО или башенный кулер, размеры и десятки других. Подбор выбирает только из подходящих товаров, а окно фильтров сразу показывает, сколько таких товаров в наличии.
- **Отдельный поиск комплектующих:** новые по каталогу Onliner, объявления (б/у и новые) на Kufar, фильтр по цене и сортировка. Можно сравнить до 4 товаров, включая цену за единицу производительности.
- **Сохранение сборок,** копирование списком со ссылками и экспорт в .txt.
- Тёмная и светлая тема.

## Как запустить

### Вариант 1. Готовая программа (проще всего)

Откройте репозиторий на GitHub → **Releases** (справа) → последний релиз «ПодборПК — сборка N».
Если релиза нет: **Actions** → «PodborPK — Windows и macOS» → последний успешный запуск → внизу **Artifacts**.

**Windows**

1. Скачайте `PodborPK-…-portable.exe` и запустите. Установка не нужна.
   Есть и установщик `PodborPK-…-setup.exe` с ярлыком на рабочем столе.
2. Windows может показать «Система Windows защитила ваш компьютер»: у программы нет платной цифровой подписи. Нажмите **Подробнее → Выполнить в любом случае**.

**macOS** (12 Monterey и новее)

1. Выберите файл под свой Mac: значок яблока в левом верхнем углу → «Об этом Mac»:
   - «Чип: Apple M1/M2/M3/M4» → `PodborPK-…-mac-arm64.dmg`;
   - «Процессор: Intel» → `PodborPK-…-mac-x64.dmg`.
2. Откройте .dmg и перетащите **ПодборПК** в папку «Программы».
3. При первом запуске macOS напишет, что не может проверить разработчика: программа не нотаризована в Apple, это платная процедура.
   - macOS 15 Sequoia и новее: «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть» → введите пароль.
   - macOS 12–14: правой кнопкой по программе → «Открыть» → «Открыть».
   - Если пишет «повреждена»: в «Терминале» выполните `xattr -cr /Applications/PodborPK.app` и запустите снова.

На Mac программа ведёт себя как обычное Mac-приложение: работают Cmd+C / Cmd+V / Cmd+Q, при закрытии окна остаётся в Dock, по клику на значок окно открывается снова.

### Вариант 2. Из исходников (нужен Node.js)

1. Установите [Node.js LTS](https://nodejs.org/).
2. Скачайте репозиторий (Code → Download ZIP) и распакуйте.
3. В папке `pc-builder` запустите:

| Что | Windows | macOS |
|---|---|---|
| Приложение в отдельном окне (первый запуск скачает Electron, 1–3 минуты) | `start-app.bat` | `start-app.command` |
| В обычном браузере, ничего не устанавливает | `start-browser.bat` | `start-browser.command` |
| Собрать свой установочный файл в папку `dist` | `build-exe.bat` | `build-mac.command` |

На Mac, если `.command` не открывается двойным щелчком: правой кнопкой → «Открыть». Или в «Терминале»: `bash start-browser.command`.

Из консоли то же самое: `npm install && npm start`, `node start-web.js`, `npm run dist` (Windows), `npm run dist:mac` (macOS).

## Откуда данные

| Источник | Что берём | Как |
|---|---|---|
| **Onliner** (catalog.onliner.by) | Новые товары, минимальная цена, все предложения магазинов с гарантией | Открытый JSON API каталога |
| **Kufar** (kufar.by) | Объявления, в основном б/у | Открытый API поиска объявлений |
| **НБРБ** (nbrb.by) | Официальные курсы валют | API НБРБ (если недоступен — курс площадки Kufar) |
| DNS, 21vek, 5 элемент, Shop.by | — | Кнопки «Искать также на…» открывают поиск на сайте магазина |

Большинство магазинов, включая 21vek и 5 элемент, продают через Onliner, поэтому их цены уже попадают в сравнение по кнопке «Магазины». Сайты магазинов напрямую не парсятся: это ненадёжно и нарушает их правила. Ссылки поиска можно поправить в «Настройках».

## Как работает подбор

1. Из каталога Onliner загружаются товары **в наличии**: процессоры, видеокарты, платы, память, SSD, блоки питания, корпуса и кулеры. Загрузка идёт по ценовым диапазонам, чтобы дешёвые позиции не вытесняли дорогие. Это 50–70 запросов, результаты кэшируются на 15 минут.
2. Из коротких описаний извлекаются характеристики: сокет, чипсет, тип и объём памяти, мощность, сертификат БП, размеры корпуса.
3. Процессоры и видеокарты сопоставляются со встроенной таблицей производительности (около 160 CPU и 100 GPU; RTX 4060 = 100, Ryzen 5 5600 = 100).
4. Перебираются все совместимые комбинации: десятки тысяч за доли секунды. Блок питания подбирается по пиковой нагрузке с запасом, кулер — по тепловыделению процессора, корпус — по формату платы. Выигрывает комбинация с лучшей оценкой для выбранного назначения в рамках бюджета.
5. Если заданы фильтры Onliner, они добавляются к запросам подбора: списки значений пересекаются с условиями подбора, диапазоны сужаются. Если фильтры и условия противоречат друг другу (например, только DDR4 и только AM5), приложение предупредит.
6. Малоизвестные бренды видеокарт и плат (часто это восстановленные карты) получают штраф. В «Тонких настройках» их можно исключить полностью.

Индексы производительности приблизительные. Они нужны для сравнения вариантов между собой, а не для точного предсказания FPS. Перед покупкой проверяйте наличие и характеристики на странице магазина.

## Структура

```
pc-builder/
  main.js              оболочка Electron: окно, меню macOS, внешние ссылки в браузере
  start-web.js         запуск без Electron, в браузере
  server/
    server.js          локальный HTTP-сервер и API (только 127.0.0.1)
    builder.js         подбор сборки под бюджет
    filters.js         фильтры Onliner: описание и объединение с условиями подбора
    perfdb.js          таблицы производительности CPU/GPU, распознавание моделей
    parsers.js         разбор описаний товаров в характеристики
    currency.js        курсы валют (НБРБ → Kufar → примерные)
    providers/         Onliner, Kufar
    store.js           сохранённые сборки и настройки (JSON-файл)
  web/                 интерфейс (HTML/CSS/JS без фреймворков)
    compat.js          проверки совместимости и расчёт БП (общий для сервера и интерфейса)
  test/run.js          тесты: npm test (с живыми данными: node test/run.js --live)
```

Данные пользователя (сборки, настройки) хранятся:
- Windows: `%APPDATA%\ПодборПК\data\data.json`;
- macOS: `~/Library/Application Support/ПодборПК/data/data.json`;
- при запуске через браузер: `~/.pc-podbor/` (на Windows — `%USERPROFILE%\.pc-podbor\`).

# Шрифты

Lora и Poppins скачаны с Google Fonts и распространяются по лицензии SIL Open Font License 1.1 (https://openfontlicense.org). Их можно бесплатно использовать в коммерческих макетах.

- Poppins Light — только латиница: логотип «IRON PRINCE», как на визитке.
- Lora — все русские тексты: курсив для заголовков, прямой для текста, вразрядку для надзаголовков.
